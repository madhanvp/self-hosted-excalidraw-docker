# Self-Hosted Excalidraw using Docker (WSL2)

This repository shows how to self-host **Excalidraw**, an open-source virtual whiteboard, using **Docker Compose** from **WSL2 (Ubuntu)**.

Excalidraw is used in my productivity stack for:
- DevOps architecture diagrams
- Workflow planning
- Daily task visualization
- Automation design sketches

---

## Tech Stack
- WSL2 (Ubuntu)
- Docker
- Docker Compose
- Excalidraw (official Docker image)

---

## Prerequisites
Make sure the following are installed:
- Docker (Docker Desktop with WSL2 enabled)
- Docker Compose
- WSL2 (Ubuntu)

Check:
```bash
docker --version
docker compose version
